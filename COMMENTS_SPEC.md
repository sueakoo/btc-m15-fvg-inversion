# ШАГ 1. Таблица выводимости

Что вообще можно утверждать. Всё, чего нет в левой колонке, в текстах запрещено.

## Доказуемо

| # | Факт | Откуда |
|---|---|---|
| Д1 | Открытый интерес вырос → открылись новые пары позиций | каждый контракт это один лонг и один шорт |
| Д2 | Открытый интерес упал → пары закрылись | то же |
| Д3 | Открытый интерес не изменился → позиции сменили владельца | то же |
| Д4 | Знак CVD показывает, кто бил по рынку; противоположная сторона стояла в заявках | определение CVD |
| Д5 | Ликвидация шорта — принудительная покупка; ликвидация лонга — принудительная продажа | механика ликвидации |
| Д6 | Агрессивная покупка при падении открытого интереса = закрытие шортов | Д2 + Д4: покупатель, который закрывается, это шорт |
| Д7 | Агрессивная продажа при падении открытого интереса = закрытие лонгов | Д2 + Д4 зеркально |
| Д8 | Цена закрылась за границей зоны | факт детекции |
| Д9 | Величины: набор, остаток, доли объёма, доля ликвидаций, тело свечи | поля данных |

## Не доказуемо — в текстах запрещено

| # | Чего утверждать нельзя | Почему |
|---|---|---|
| Н1 | Кто вышел или зашёл первым | порядок сделок внутри свечи не виден |
| Н2 | Намерения участников: «скрытно», «не спешил», «крупный игрок» | в данных нет |
| Н3 | Чем именно заместили закрытые позиции при неизменном открытом интересе | виден только итог |
| Н4 | Куда пойдёт цена и как долго продержится | не следует из измерения |
| Н5 | «Движение целиком из принудительных ордеров» | ликвидации это доли процента от оборота, даже 0.3% — малая часть объёма |

# ШАГ 2. Словарь

Разрешено только это. Что вне списка — использовать нельзя.

**Позиции:** позиций стало больше / позиций стало меньше / число позиций не изменилось / позиции сменили владельца / открывались новые позиции / позиции закрывались.

**Агрессия:** бил по рынку / принимал заявками / по рынку никто не бил.

**Ликвидации:** выбивало по стопам / принудительные закрытия / выбивало лонгов / выбивало шортов / доля принудительных закрытий.

**Зона:** зона, имбаланс, прошли зону, закрылись за зоной, до зоны, внутри зоны, на инверсии.

**Стороны:** покупатель, продавец, лонги, шорты. Подставляются по направлению сделки.

**Запрещено:** своё, поверх, топливо, маскировка, не спешил, скрытно, крупный участник, лучший случай, сомнительна, каскад, первыми выходили, ресурс, сила.

# ШАГ 3. Шаблон

Три слота, третий необязательный:

`[что стало с позициями] + [кто был активной стороной] + [что это значит для уровня]`

Третий слот заполняется **только если** следствие выводится из первых двух.

# ШАГ 4. Лимит

Не больше двух простых предложений. Цифры в заголовке блока — комментарий их не повторяет.

## БЛОК 2 — Размещение позиции

Заголовок: `до зоны и внутри: {C}%, внутри зоны: {F}%`

| доля до зоны и внутри | лонг | шорт |
|---|---|---|
| 80% и выше | Почти всю позицию набрали до зоны и внутри неё. Ниже уровня есть подушка. | …Выше уровня есть подушка. |
| 60–79% | Основную часть позиции набрали до зоны и внутри неё. | то же |
| 40–59% | Часть позиции набрана до зоны, часть — у самой инверсии. | то же |
| 20–39% | Большая часть позиции набрана у самой инверсии. | то же |
| меньше 20% | Позицию набирали у экстремума движения. | то же |

Добавка про долю внутри зоны:
- 40% и выше: « Заметная доля — внутри зоны.»
- 10–39%: « Внутри зоны доля небольшая.»
- меньше 10%: « Внутри зоны позиции нет.»

Когда балл срезан потолком:
- « Балл ограничен: набрано меньше 0.20%.»
- « Балл ограничен: в окне {n} свечи.»

Приписка про ликвидации (при доле 0.1% и выше):

| выносило | OI | приписка |
|---|---|---|
| шортов | НАБОР | Выбивало шортов — часть покупок была вынужденной. |
| лонгов | НАБОР | Выбивало лонгов, их продажи выкупили. |
| шортов | СНЯТИЕ | Выбивало шортов — позиций стало меньше за их счёт. |
| лонгов | СНЯТИЕ | Выбивало лонгов, замещения не было. |
| поровну или неизвестно | любой | приписки нет |

Приписка про тело:
- 60% и выше: « Свеча закрылась у края диапазона.»
- 35–60%: приписки нет
- меньше 35%: « Свеча закрылась далеко от края.»

Нет данных:
- «Данных по агрессии нет, механика определена по открытому интересу.»
- «Ликвидации не определены, известно только что их не больше {M}%.»

# ЗАКЛЮЧЕНИЕ

Собирается из четырёх частей: механика прохода → что подтверждает → ликвидации → ожидаемый тест.

Вступление берётся из комментария блока 4. Строка про ликвидации — из блока 9. Процент отработки убран. Все формулировки подчинены тем же правилам.
